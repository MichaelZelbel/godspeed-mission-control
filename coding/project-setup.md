# Add a coding project to your mission control

Requests from Chapter 4 of Teach It Once. Use your assistant with access to your mission control folder.

## Add a project

Paste the GitHub link after this request, or name a project your assistant already knows.

```
Clone this repository into dev/ inside my mission control.
```

## Check the histories

```
Check that the projects inside dev/ have their own Git histories and are excluded from the mission control's history. Keep dev/README.md in the mission control's history. Check a real project file and preview what the mission control would save. Tell me which file you checked and what you found. Do not delete anything or change existing history.
```

## Check project instructions

```
Check the instructions for this project and the AI tool I am using. Show me the instruction files this session received, including any account-wide instructions. If you can only show that a file exists, say so. Read the mission control's AGENTS.md and this project's instruction files. Explain any conflicting instructions and propose a correction. Keep existing instructions until I approve a change.
```
