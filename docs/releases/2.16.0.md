# every move bets on a weekly number, and Windows is level with macOS and Linux
The kit for *Teach It Once*, updated 2026-09-30.

**What changed since v2.6.0**

- **Each goal names one weekly number, and every move bets on it.** When your assistant plans the day's moves, each move says which number it should change. Seven days later the numbers settle it: the move worked, or it did not, and the next plan knows which.
- **A deadline can have a target beside it.** The target is the day you would like something done; the deadline is the day it starts costing you. A missed target gets one question ("a new date, or as soon as you can?") and then a quiet line about once a week, never an alarm.
- **Your recipes stay current unless you changed them.** When you install or update, a recipe you never edited is replaced by the kit's newest version. One you edited is left exactly as you wrote it.
- **One question about counting installs, asked once per computer.** At the end, the installer asks whether this computer may report that the install worked. The answer starts as no, and with no, nothing is sent. With yes, it sends one word, "installed", with the version, the kind of computer and a random number made for this computer, and nothing about you.
- **Windows repairs.** The moves check now runs on Windows, running the installer again over a mission control that has no saved version yet updates it instead of stopping, and Windows PowerShell 5.1 now merges the Claude Code settings correctly.
- **One version number on every platform.** From this release the installer's number is the number of the code it installs, the same on Windows, macOS and Linux. That is why it jumps from 2.6.0 to 2.16.0. Every Windows installer is now built and tested on a fresh Windows machine before it is published.
