# Habit progress picture

Reading this as: a private progress receipt, in Operate mode, viewed at phone width inside Telegram.
Vibe: calm, forgiving, plain, readable.

Brief: "over the days, we can probably put the weekdays" and "very easy to read."
The person should see that completed effort remains, and identify what happened on each recent day.
The next action is their existing meaningful habit minimum. This picture adds no button or reminder.
All counts and calendar states come from the authoritative coach progress result. Previews are fictional.

Plan v1: lifetime and current count above a seven-column calendar, with weekday and short month labels.
One light paper canvas, dark green ink, a muted green surface. Noto Sans at 26px minimum on an 840px canvas.
Phone composition: title, tiny action, two counts, seven days, text legend. No animation or external imagery.

Review: lifetime count remains larger so a new run does not erase earlier effort. Current streak is explicitly
measured in completed days, excluding protection and pauses. Calendar symbols differ by shape, including
explicit "not done" versus an unresolved record gap. Plain month names remove numeric date ambiguity.
Calm mode hides the streak. Long text wraps and long numbers shrink to their column width.

Plan v2: use the reviewed composition. The embedded PNG is its own deterministic artifact, not a webpage.
SVG text escapes source data. PNG generation uses the bundled OFL font rather than browser/system fonts.
Phone review raised essential text and dates to 34px and legend text to 38px; lifetime labels use two lines.
Verification: inspected full-resolution, 320px and 390px PNG previews; test dates, state provenance, escaping,
calm mode, large counts, repeated rendering, authenticated reply transport, and uncertain delivery behavior.
