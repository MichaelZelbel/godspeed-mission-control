# Local progress picture font

Noto Sans, distributed under the SIL Open Font License in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/notosans
Downloaded 2026-10-13 from NotoSans[wdth,wght].ttf.
SHA256: bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d.

The font bytes are bundled so pictures never request a remote font or vary with installed fonts.
ImageScript's existing vendored WASM rasterizer and font renderer produce the PNG locally.
