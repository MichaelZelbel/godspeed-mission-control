# Habit progress illustrations

Original code-native artwork for Godspeed Mission Control, distributed under the repository's AGPL-3.0-only license. These are generic progress characters, not a new product logo or identity.

Each stem has a transparent 256 by 256 SVG original and matching PNG rendering:

- `flame-ready`: a friendly invitation, used for the active habit hero.
- `flame-done`: a delighted flame, used only for completed calendar dates and the completed hero.
- `flame-ice`: friendly flame inside faceted cyan ice, for protected dates and freeze inventory.
- `flame-rest`: resting flame, for pauses and planned rest.

Past unknown dates use neutral dots; an undone today uses a neutral unlit spark in each renderer. Neither is shown as a completed flame. Source SVGs are imported by the web bundler; the image composer reads PNG siblings. Rasterized with Chromium from the SVG originals. No font, emoji or external image dependencies inside these illustrations.
