# Credits and licences

This skill is Godspeed Mission Control's own distillation, written 2026-09-23
by Michael Zelbel with Claude. It combines rules from the public skills below
(read at their source on that date) with lessons from building Michael's own
sites. Rules were selected, merged, reworded and in places contradicted;
nothing here is an unmodified copy of any source file.

The skill itself is released under the MIT licence (below). Material from
Apache-2.0 sources remains under Apache-2.0; see `LICENSE-APACHE-2.0.txt`.

## Sources

- **frontend-design** by Anthropic. Apache-2.0.
  https://github.com/anthropics/skills/tree/main/skills/frontend-design
  Used: the five default looks (calibration.md §1, lightly edited), plan then
  review against the brief, the twin test, one bold move, interface copy
  rules. Modified: reworded, merged with other sources, dashes removed.
- **Impeccable** by Paul Bakaus. Apache-2.0. https://github.com/pbakaus/impeccable
  Used: four visitor modes, colour strategies, light or dark from the use
  scene, the craft floor as checks on the render, browser surfaces, the font
  defaults list, bounded verification rounds, the fresh-context reviewer.
  Modified: reworded and condensed; tooling not included.
- **frontend-skill** by OpenAI (withdrawn 2026-04-23; read at commit
  82d2c5b44a). Apache-2.0. https://github.com/openai/skills
  Used: the poster-first viewport, the image and nav removal tests, the
  sticky header counting against the hero, cutting 30 percent of the copy.
- **taste-skill** by Leonxlnx. MIT. https://github.com/Leonxlnx/taste-skill
  Used: the one-line design read, countable hero rules, the premium-consumer
  palette hex families, one label per intent, production tells list.
- **scroll-craft** by Nate Herk. MIT. https://github.com/nateherkai/scroll-craft
  Used: much of the taste floor (spacing, type, colour, depth, cards, the
  re-ink bug, scrim rules), the refuse list, the Chrome-finding approach in
  the check script. Immersive scroll builds are routed to scroll-craft itself.
- **Emil Kowalski's skills**. MIT. https://github.com/emilkowalski/skill
  Used: whether to animate by frequency, easing curves, duration table,
  press feedback, reduced motion as gentler rather than none.
- **Web Interface Guidelines** by Vercel Labs. MIT.
  https://github.com/vercel-labs/web-interface-guidelines
  Used: code-level anti-patterns (zoom, paste, labels, `transition: all`),
  typography details, dark mode browser chrome.
- **UI/UX Pro Max** by Next Level Builder. MIT.
  https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
  Used: touch target size, exit faster than enter.
