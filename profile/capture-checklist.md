# Chapter 8: Tell Mission Control Once, Let It Remember

A client changes the budget during a call. You mention it to Mission Control while asking for help with the proposal. That conversation should do two useful jobs: help with the proposal and keep the changed budget for next time.

You should not have to choose a folder, write a tidy note, then return later to process it. Mission Control can handle the filing while the detail is still fresh.

## Say the useful sentence

The matching companion kit tells the assistant to save useful facts during ordinary conversation, check the saved result and briefly confirm what it kept. It also tells it to update the short briefing when the fact changes current work. This happens during a session; checking while you are away needs a scheduled job.

Here is an example using Nadia, the fictional client from the earlier chapters. Read it as a sample of natural wording, and use your own update in your real mission control:

```
Nadia said today the budget for next year's book has doubled. She hinted there could be a second illustrated title in it for me.
```

The assistant has two different things to keep: a reported budget change and a possible second project. “She hinted” stays a hint. It should not create an agreed project, invent a price from an unknown starting budget or send Nadia a delighted acceptance.

It can use the budget update when helping with the proposal. If it needs the original amount, it should search the existing notes before asking you.

## Let Mission Control handle the filing

Clear information goes into Mission Control's saved record during the same conversation. The assistant keeps the source and date. If a new value replaces an old one, it records the change and updates the current briefing where needed.

The inbox is a holding place for something the assistant cannot settle yet, such as a note with an unclear date. It is also useful for raw material you explicitly want left untouched. It does not need to become your second job.

When you answer a question about a saved uncertainty, Mission Control should finish filing that note. An unresolved detail can wait until it affects real work. The assistant should not interrupt a draft to ask about an unrelated scrap of paper.

This behaviour is included in the matching companion instructions applied during setup. There is no separate filing prompt to remember.

## Why I changed the old inbox method

In a practice run on 2 September 2026, I explicitly asked for an inbox capture. The reply was:

> Captured in: inbox/2026-09-02-nadia-book-budget.md

The file existed, but I still had to ask for another pass to put its contents to use. Saving the note was only half the help. The revised instructions give the assistant responsibility for finishing the filing during the conversation.

I also tried a save request with another assistant in four clean folders. It gave four reassuring replies and left four untouched folders. It had used its own storage on that computer. That experience is why Mission Control's instructions require checking the actual saved record.

When you first try this, use one harmless fact and ask about it in a fresh session. Mission Control should find the saved source. If it cannot, let it trace and fix the saving or retrieval step. This is a check of the setup, not a ritual for every note.

## Remember what helps the work

Not every sentence deserves a permanent record. A useful change might be a new agreement, a decision or something you learned from a job. “Sending Nadia three options reduced revisions on this job” gives the assistant a specific result to consider next time. It does not prove that every client wants three options.

Your instructions matter too. “Ask before sending anything in my name” is a rule to follow. “I liked that short answer” is feedback on one answer. The assistant should keep that distinction instead of quietly declaring that you now dislike paragraphs.

Keep passwords and access keys out of these conversations. A useful note about another person needs only the detail required for the work.

## Find the right note when it matters

My first design loaded a summary of every note into every session. The list reached 108 lines, including material that had nothing to do with the current request.

Lauren Contalonis's account helped me separate keeping a note from bringing it into today's work. One sentence stayed with me:

> Not everything safe enough to keep should remain hot enough to influence today's thinking.

The source is her [13 August 2026 article on what an AI system should reach, remember and use](https://www.linkedin.com/pulse/3-expanding-stage-2-what-my-ai-harness-should-reach-use-contalonis-azwpc). Here, “hot” means information kept ready for frequent use.

Mission Control keeps a short briefing and searches the larger record when a subject comes up. The assistant handles that choice. You tell it what happened, carry on with the work and get the benefit when the information matters again.
