# Chapter 9: Let Mission Control Keep Up With Your Life

“The client accepted the final version. Help me write the invoice.” That sentence gives Mission Control a job and a change to remember. It can prepare the invoice and mark the delivery complete while it is there.

That one update is enough for both jobs. Mission Control can keep its notes current while preparing the thing you asked for.

## Let conversation update the record

The matching companion instructions tell Mission Control to keep current notes in step with clear updates you give it. It checks what is already saved, records what changed and uses the new information in the work at hand.

A new address replaces the old current address. A completed delivery leaves the active delivery list. The earlier facts remain dated history, so the assistant can still explain an old decision when you need it.

Completion has a scope. A client accepting a delivery does not prove the invoice has been paid. Mission Control should keep the remaining work visible without reopening the finished part. A useful assistant can let the illustration job end and still remember the invoice.

## Ask when there is a real reason

Sometimes Mission Control finds two incompatible answers. Before drafting a message or making a recommendation, it should check the relevant notes and newer evidence it can access. If those sources settle the question, it can update the record. If they don't, it should ask you one clear question.

In an earlier review of Sam's fictional July files, the assistant found two versions of a deadline:

> **"End of the month" vs 2026-07-28.** `about-me.md` says the card set is due "end of the month". `projects.md` pins it to Tuesday 2026-07-28. Those are 3 days apart. Which one is right?

The question is useful because the answer changes the plan. If a newer agreement were available, Mission Control should read it first. Sam should only have to answer when the saved material cannot resolve the difference.

The same review found a possible gap:

> **Third regular client missing.** `about-me.md` lists three regulars: board-game studio, children's book publisher, and a coffee brand. `people.md` has no coffee brand entry. Either the coffee brand is inactive or the file is incomplete.

That gap matters when preparing work for the coffee client. It need not interrupt a conversation about something else. Mission Control can keep the question until it has a purpose. A missing entry is also not permission to invent a contact's name.

## Age is a clue, not a verdict

A passed deadline gives Mission Control a reason to check what happened. It does not prove the work finished. An old job title may still be correct. A budget that has not changed does not need a new date to stay respectable.

The assistant should look for evidence of change before changing the record. If it only suspects something, it should keep that uncertainty visible. “The deadline has passed; I cannot find a delivery confirmation” is useful. Quietly marking the job complete would hide the very thing you need help with.

## Use the updated background in real work

You don't need a separate information-cleaning session. Ask for help with the work itself:

```
What needs my attention on my current projects? Use my saved priorities and recent updates you can access. Check relevant old or conflicting notes against newer evidence before recommending a next step.

Update clear changes in Mission Control's records, preserving sources and dated history. Do not infer completion from a passed deadline or a recently edited file. Ask me only about an unresolved point that changes the recommendation. Prepare useful work where you can, and leave external actions for my approval.

If sources disagree and neither settles the difference, ask before relying on the disputed value. Do not invent different meanings for conflicting dates. Continue with the undisputed parts of the work. Do not add reminders, deadline entries or schedules as part of this request.
```

The same checking belongs in an ordinary request for a draft or decision. The longer wording above makes the behaviour explicit when you first try it. The companion instructions tell Mission Control to keep doing it without waiting for that exact prompt.

When a correction is needed, a short confirmation tells you what changed. You don't need a tour of every file it touched. If an answer is wrong despite a correct source, the assistant should fix its reasoning instead of rewriting the source to match its mistake.

## Keep the limits practical

Mission Control can use conversations and sources it can reach. It cannot know about a phone call you have never mentioned or read an account you have not connected. An ordinary update during your next conversation gives it something to work with.

While the assistant is running, it can check relevant information as part of the job. A scheduled morning brief or weekly review can do that when you are away, once you have set one up. Until then, there is no background check between sessions.

You carry on with your life. Mission Control keeps the useful record as part of helping you live it.
