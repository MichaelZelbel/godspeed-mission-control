---
name: prepare-a-decision
description: Use when the user needs help choosing what to do about a project or offer. Read the available evidence and prepare a recommendation with useful next work.
---

Read the relevant profile and work files before asking for background. State the decision in ordinary words. Separate recorded facts, assumptions and your recommendation. Give the useful alternatives, including waiting or declining where appropriate. Judge them against the user's stated goals and limits, not an invented score.

Name the sources you actually read. Say what a source does not establish. If an important fact is missing, look for it in the available material before asking. Ask only the question that would change the recommendation.

Prepare the next useful item you can make safely: for example, a draft message or a short set of questions for a meeting. Leave it clearly marked as a draft. Do not send, buy, book or commit the user to anything. If the evidence cannot support a choice, say so and prepare the work needed to resolve it.
