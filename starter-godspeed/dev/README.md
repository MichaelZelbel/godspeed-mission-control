# Coding projects

Keep projects you actively work on in this folder. Each project has its own folder and Git history.

## The rule

Mission Control's `.gitignore` excludes the projects from Mission Control's history and keeps this project list. This affects what Git saves, not what the assistant can read or change.

## What belongs here

Projects you and your assistant work on regularly. Before removing a dormant project, have the assistant check for edits and commits that have not reached GitHub. A new clone would not recover those. Deleting a local copy requires your approval.

## How to use

Ask by project name, for example:

```
Clone the Menerio repository into dev/ inside my mission control.
```

The assistant should check the available GitHub account, find the repository, and guide sign-in or ask which project you mean only when needed. It checks for an existing copy before cloning, verifies the result and reports where the files are. Mission Control's `AGENTS.md` holds the full instructions for this work.
