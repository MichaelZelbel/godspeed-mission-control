# Inbox

What is not settled yet waits here, one small file per capture: a question that
still needs an answer, writing samples (Chapter 8 keeps them in
`inbox/writing-samples/`) and material you asked to keep untouched. Name
captures by date, for example `2026-07-26-nadia-book-budget.md`.

Clear, useful facts from a conversation do not wait here. Your assistant files
them during the work (Chapter 9), so you never have to come back with a sorting
request.

When a doubt is settled, by newer evidence or by your answer, the assistant
finishes filing it in that conversation and moves the original into
`archives/filed-captures/` under a unique name, making that folder the first
time it needs it. Writing samples, open import questions and unrelated captures
stay here. It asks about a doubt only when the answer changes the current work.

A proposed behaviour rule is not a profile fact. It waits here until you
confirm it, then goes into `rules/` and through `mc-compile-rules`. A weekly
review (Chapter 24), once you set one up, files the remaining clear captures
the same way; you do not need one to use a new fact today.
