# Saved prompts

Keep prompts you deliberately want to reuse, one Markdown file per prompt. Add a short purpose and source/date at the top. Ask the assistant to search this folder when needed; old prompts are not current instructions.

Chapter 12 explains reusable prompts. Chapter 23 saves the current Chapter 1 context-summary prompt here. Chapter 1 itself does not export a collection of earlier prompts.

A skill belongs in skills/ when you intend the configured assistant to discover and run it. A library prompt is retrieved deliberately. Either is readable text; the difference does not mean a tool can never read or use it.

Chapter 33 shows an optional online copy. Review private details before sharing, compare changes on return and retain one chosen master with version history. The conversation archive beside this folder is optional and may be empty.
