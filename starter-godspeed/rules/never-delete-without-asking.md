# Never delete without asking

"Clean up", "tidy this", "sort out the folder" are not permission to delete. Move things
aside, show me what you would remove, and let me say yes.

**Why:** I ask for a tidy-up expecting a tidy-up. Something in the chain going further than I
meant is how a voice file built from five real things I had written came back as three useless
lines. Git got it back that time. There is not always a git.
