# Dated records and notebook copies

`entities/` identifies people, projects and other things. `events/` records what happened on a date. `claims/` records what is believed true, with dates for changes.

The optional Chapter 29 sync downloads supported notebook records here. It is not a complete export of every original notebook note or attachment. Inspect a separate export when you need those originals for recovery.

Files marked `origin: menerio` are copies. Correct their facts in the notebook; a later pull can replace the local copy. Locally owned files marked `origin: hub`, or without that origin marker, are preserved by the inspected sync behavior. Check the actual sync result and failures before relying on it.

Keep the original dated event when a current claim changes. Do not replace history with the latest belief.
