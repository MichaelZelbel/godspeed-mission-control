# Optional model routing

OpenRouter is one possible intermediary for reaching a model. Chapter 37 used it in an earlier test, with the model `moonshotai/kimi-k3` that `opencode.json` still names; it is not required. Have the assistant check the current provider, model availability, data route and price before configuring access. Authenticate in a secure local prompt, not in chat. The local files can be tested without Menerio.
